# ClarityFund Contract

A decentralized funding contract designed to manage pooled capital,
evaluate grant proposals, and distribute funds through governance approval.

## Key Functions
- `create-fund` — Initialize a new funding pool
- `contribute` — Add capital to the fund
- `submit-grant` — Propose a funding request
- `approve-grant` — Approve grant through governance
- `disburse-grant` — Release approved funds
- `get-fund-balance` — View total pooled capital

Designed for ecosystem grants, builder incentives, and DAO-managed funding programs.
